## 2024-10-26 - Emanote Template Search Button & Focus Ring Accessibility
**Learning:** In Emanote Heist templates, custom action triggers (like the Search icon) defined as `<a>` tags without `href` attributes are omitted from keyboard tab navigation and lack default button keyboard event handling. Adding `role="button"`, `tabindex="0"`, and an `onkeydown` handler enables screen reader accessibility and keyboard trigger support via Enter and Space keys. Furthermore, combining `focus-visible:ring-2` with dynamic theme variables ensures consistent visual focus indicators without affecting mouse clicks.
**Action:** When working with Heist templates (`.tpl`), always verify that non-link clickable elements include `role="button"`, `tabindex="0"`, keydown handlers, and Tailwind `focus-visible` ring utility classes.
